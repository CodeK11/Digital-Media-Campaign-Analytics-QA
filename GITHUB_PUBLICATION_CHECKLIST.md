# GitHub publication checklist

Before publishing, add the locally exported `data/processed/ga4_web_analytics.csv` and the native `powerbi/Digital_Media_Campaign_Analytics.pbix` (if you intend to publish the PBIX). Add screenshots under `powerbi/screenshots/`.

- [ ] Confirm README clearly labels campaign data as simulated.
- [ ] Confirm GA4 data is identified as historical public web analytics.
- [ ] Include source query and extraction guide.
- [ ] Include final PBIX or screenshots; never claim the PBIX is included if it is not.
- [ ] Check for credentials, private client data, personal data or local machine paths.
- [ ] Ensure CSV files and PBIX open from the repository folder.
- [ ] Commit the final project and verify the GitHub repository renders the README correctly.
